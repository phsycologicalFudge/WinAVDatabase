# ColourSwift WinAVDatabase

## Overview

The ColourSwift WinAVDatabase repository contains the virus-definition database and supporting data used by VX-TITANIUM, the offline antivirus engine powering CS Secure Files,[ CS Security](https://github.com/phsycologicalFudge/ColourSwift_AV) and future ColourSwift security products.

This repository exists to distribute verified definition updates and public releases from the official ColourSwift website.

Note: Older folders such as release/ and vxpack_raw are deprecated and no longer used.
